# Приложение «Мобильный хоспис»

Android-приложение с авторизацией, новостями, панелью управления новостями и разделом «Наша миссия».

В проекте есть 20 автотестов на Java, Espresso и JUnit 4. Для запуска используется Android Studio.

## Как подготовить проект

1. Запустить Android Studio и нажать **Open**.
2. Выбрать папку `fmh_android_updated` и дождаться загрузки проекта и синхронизации Gradle.
3. Если Android Studio предложит установить недостающие компоненты Android SDK, согласиться с установкой. Проект использует **Android SDK 36**.
4. В настройках **Settings → Build, Execution, Deployment → Build Tools → Gradle** выбрать **Gradle JDK 21**.
5. Открыть **Tools → Device Manager** и создать эмулятор **Pixel 6a с Android 16 (API 36)**. 
6. Запустить эмулятор кнопкой ▶ рядом с его названием. Для тестов нужны интернет, английский язык интерфейса и обычный размер шрифта.

## Как запустить тесты

1. В левой панели проекта найти папку:
   `app → src → androidTest → java → ru → edu → qamid → tests`.
   Если папки не видны, выбрать режим отображения **Project** в верхней части панели.
2. Нажать правой кнопкой на пакет `tests` и выбрать **Run Tests** — название пункта может содержать имя пакета.
3. Если появится выбор устройства, указать запущенный эмулятор.
4. Дождаться завершения. Результаты появятся в нижнем окне **Run**: зелёные тесты прошли, красные завершились с ошибкой. При выборе красного теста можно увидеть причину.

Чтобы запустить один класс или один тест, открыть нужный Java-файл в папке `tests` и нажать зелёный треугольник слева от названия класса или метода.

Тесты сами выполняют вход. Учебная учётная запись: `login2` / `password2`. Созданные тестами новости имеют префикс `AUTO_` и остаются на учебном сервере; отдельный тест удаления удаляет только свою запись.

## Как посмотреть Allure

Открыть файл [reports/allure/index.html](reports/allure/index.html) в браузере.Устанавливать Allure для его просмотра не нужно.

Исходные результаты того же прогона лежат в [allure-results.zip](allure-results.zip).
